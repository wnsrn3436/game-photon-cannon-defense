# 포토캐논보호하기

스타크래프트를 소재로, 몰려오는 마린과 레이스로부터 포토캐논을 지키는 디펜스 게임이다. 드래그 선택과 이동 명령이 되는지 확인해보려고 만들었다.

</p>


## 플레이 방법

Releases에서 받아 실행하면 된다.

좌클릭 드래그로 질럿 여러 기를 한 번에 선택하고 우클릭으로 이동 명령을 내린다. 마린과 레이스가 계속 몰려오니 포토캐논이 부서지지 않게 막아야 한다.

건물이 3개 파괴되면 패배한다. 킬 수가 40이 되면 자원과 질럿이 늘고, 80이 되면 적이 레이스로 바뀐다. 파괴된 건물 수와 킬 수는 창 제목표시줄에 나온다.


## 구현 원리

드래그 선택은 전역변수 두 개와 좌표 비교로 만들었다. 마우스를 누르는 순간 그 지점의 x, y를 전역변수에 저장해두고 선택 박스를 그린다. 버튼을 놓는 순간 모든 질럿이 각자 자기 좌표가 저장된 지점과 현재 마우스 지점 사이에 들어가는지 드래그 방향별로 네 번씩 비교하고, 조건을 통과하면 선택된 상태의 질럿 오브젝트로 자기 자신을 바꾼다.

선택 여부를 변수로 들고 있는 게 아니라 오브젝트 종류로 구분했다.
